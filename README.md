## 📂 Project Structure

* `ServerScriptService/` — Scripts running directly on the Roblox Engine Server.
* `ReplicatedStorage/` — Luau modules and shared files between server and client.
* `StarterPlayer/` — Extracted local logic controlling player behavior.

## 🛠️ Extraction Tools

The files were extracted using:
* **Roblox Studio API / Dump Tools**
* **Language:** Luau (a modern extension of Lua 5.1 optimized by Roblox).
